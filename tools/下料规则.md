# 下料展开规则（按 NO.441 人工图 + 历史人工图纸 + 用户确认整理）

> 读图口径（图层、投影、孔标注写法、技术要求、BOM/镜像）见 `tools/图纸识读规范.md`。

## 输出格式
- 排版：列间距 = 上一列（零件几何 + 绿色标签 + 黄色表头）包围盒右端 + 750（`tools/layout.py`，`tools/check_layout.py` 自检）。
- 每个零件函数返回 `[(C.lab(厚度, 件数[, 材料]), Piece), ...]`。件数 = 订单数量 `q` × 每台用量（组件按 BOM 明细）。
- 绿色标签只写 `材料-厚度,件数`，如 `SUS304-3mm,2件`、`Q235B-5mm,4件`，禁止加其它字。型材/管材写 `材料-长度mm,件数`（`C.lab(长度, 件数)`）并画截面（`C.tube_rect` / `C.tube_round`）。
- 外购件、机加件（轴、螺杆、标准件）不下料，不出标签。
- 老图标注（`tools/oldparts.py`，排版时自动做）：物料号在历史图纸里做过的，黄色表头末尾加“老图NO.xxx”（同历史“·更新”写法）；
  历史已有更高版本的，加“老图A版(NO.xxx已做B版)”并在表头下方写红字 ▲ 提醒；清单版本与图纸文件版本不一致的也写红字。
- 切割轮廓在 `可见 (ISO)` 层（Piece 默认）。轮廓必须闭合、无重复线（同一条边不能画两遍，图纸里的板厚线、反面线、倒角线、中心线、尺寸线都不要）。

## 板厚 / 材料
- 厚度取图纸：剖视图板厚尺寸、技术要求“使用 T=5MM 热板”、或重量反算。SUS304 标题栏材料为 SUS304；Q235B 件材料 Q235B。
- 无库存板厚：15mm → 16mm；SUS304 3.5mm → 4mm（`C.lab` 已自动处理）。

## 折弯展开（外形尺寸法）
- 展开长 = 各边外形尺寸之和 − 折弯数 × BD；`C.bd(t)` 给出 BD（SUS304 / Q235B 表不同，Q235B 件用 `C.bd(t, 'Q235B')`）。
  SUS304: 1→1.7, 1.2→2, 1.5→2.3, 2→3, 2.5→4, 3→5, 4→6.8, 5→8.4, 6→10.5, 8→14, 10→17。
- 某面上的特征距折弯外形交点为 s 时，展开坐标 = 该折弯红线位置 ± (s − BD/2)。
- 90° 折弯：`p.bend(x0,y0,x1,y1,BD)` 画红色中心线 + 两侧蓝线（间距 BD）。
- 非 90° 折弯（如 135°、15°、10°、120°）：按 K 因子中性层算展开（`C.bd_angle`），只画红线：`p.bend(..., 0, red_only=True)`。
- 折弯线只画在折弯区范围内（端点落在轮廓上）。
- 释放槽：只有两条及以上折弯边在角上相碰才做，样式 V 形（`C.relief_params(t, BD)` 给 p=2t, g=2t−BD, s=t+0.1；一边翻边全宽，另一边内缩 s）。不碰角的折边保留图纸原有避让，不另加。

## 孔
- 螺纹孔按小径开孔：`p.tap(x, y, 'M8')`（M3 2.46, M4 3.24, M5 4.13, M6 4.92, M8 6.65, M10 8.38, M12 10.11, M16 13.84）。
- 沉头孔、沉孔只开通孔（如 “Φ9 -3 深” 在 3mm 板上即 Φ9 通孔；沉头 Φ5.5×Φ10.4 只开 Φ5.5）。
- 带正公差的配合孔（如 Φ24 +0.021/0、H7）切割孔径 +0.1；公差上限已 ≥0.1 的按名义尺寸（历史 4020703A 的 Φ56 +0.10/+0.02 人工开 Φ56）。
- 腰形孔 `p.slot(x0,y0,x1,y1,宽)`（两端圆心）。

## 取图纸几何
- 平板件优先直接取视图：`C.plate('文件.dxf', (x0,y0,x1,y1))`，区域稍大于视图外形，会自动去掉同心大圆。
- 视图比例非 1:1（标注值 ≠ 图形长度）要 `.scaled(k)` 还原；有打断画法的用 `C.extract_unbroken`。
- 折弯件的平面视图如果就是真实形状，可先 `C.plate` 取出再在折边处补展开（`C.fold_edge`）；否则按尺寸用 `p.outline([(x,y,圆角R),...])` 手工建模。
- 镜像件（图纸“镜像制作”表）：`C.mirror('镜像件号', '源件号')`。

## 三维拆图（STEP / SLDPRT，`tools/step_split.py`）
从淳楚1028（厚晨，客户松川远亿）125 个带 3D 的件学来：3D 拆出的件与客户平板 DWG 外形、板厚、件数逐件对上 94/124（孔径小差另计），与我们的老图对上 38/43。
- 客户常把整个焊接件存成**一个实体**（板、筋、加厚板、方管、焊接螺母合在一起），不能整体展开，先拆：
  - 板 = 一对平行反向平面、间距 t、投影重叠；两平面之间是空腔的不算（方管两壁）。
  - **加厚板**贴在板面上焊死：看到“总厚 = 本板 + x”时，加厚板厚 x、外形 = 重叠区（ZX660T1110V 3+4、ZX660T1217V）。
  - 内壁被焊上去的筋板切碎的同一面并成一块；**筋板 / 端板**单独成件（ZB700S01xx：U 槽 + 4 块 67×64 筋 + 67×37 端板，与老图一致）。
  - 同厚、相邻、中间是圆角的两块板 = 一件折弯件，**不论圆角是否同心、内角是不是尖角**（模型常把折弯画成普通倒圆：
    TD690T170342V 内 R5 外 R10，ZX660T1226V 内角尖、外 R2）；外形尺寸法展开与圆角无关。
  - 折弯连成闭环、细长 = **管材**（GB/T 6728 矩形管 20×10×1 等），不进板料图，另列管材；六角带孔小件 = 外购焊接螺母，不下料。
  - 单块厚板（有沉孔、台阶）：外形取最大平面的投影，板厚 = 该方向整体厚度（TD690T3024V 42×15 t15、ZB700S170425V 65×20 t15）。
  - 平板孔取几个深度截面的并集：沉孔、倒角只留通孔。折弯件上的沉孔 step_unfold 取的是表面那圈（ZX690B0090V 3D 出 Φ15/17，应开 Φ9），要人工改。
- **厚晨 BD**（3D 外形尺寸和 − 客户平板图展开尺寸，反推）：Q235B 1.5→2.6、2→3.5、3→5.2、5→8.8、6→10.5、8→14；SUS304 1.5→2.6、3→5.2；镀锌 1.5→2.6。
  比我们 sheetlib 表略大（3→5、5→8.4、6→10.2、8→13.6）；我们给厚晨出过的老图也基本按这套（3mm 老图 11 件里 9 件是 5.2/5.25）。厚晨的件用 `--bd 厚晨`。
- **客户的拆法**（3D 是一体、平板图拆成几块，或反过来；照客户平板图 / “厚晨子件”PDF 做，压缩包里有就以它为准）：
  - 四边都有壁的盒子：拆成 U 形主件（底 + 两长边一起折）+ 两块端板，端板 = 内宽 × 内高（ZX690B0022CV 500×200 盒 → 949.5×600 + 2×496.9×198.5；
    ZB710E1926V 3D 是 5 块板焊的，客户和老图都折成 420×324.8 + 2×177×73.5）。
  - 6mm 尖角 L 形：两块板焊（ZX690B4511AV → 91×60 + 60×29）；3mm 小 U 形老图按一件折（TD300A0409V 72×15），客户新图拆成 41.5 + 2×17。
  - 焊接螺母孔：3D 画 Φ7，平板图 / 老图开 Φ8.1（M6 焊接螺母的定位凸台）。
- 还拆不对的：外壳类带压死边 / 非 90° 折边（TD690T05xx SUS 2mm，差 2.5~4.7）、ZX660T1217V 底板、TD690T02011x、ZX690B4579BV——照客户平板图做。

- 按折弯算扣除（2026-11-06 沃精 KD1131）：90° 且内 R ≤ 2.5t 查 BD 表；非 90° 或内 R > 2.5t（大圆弧）按中性层算，只画红线，见 `step_unfold.bend_bd`。
- 沃精的件：螺纹孔按模型底孔开（M5 4.2、M6 5.0、M8 6.8），和它的历史图一致；客户 DWG 带 SolidWorks 展开视图，模型展不开时取视图（`单件/2026-11-06-沃精KD1131/flatview.py`）。

## 做不了的
- 实在无法可靠展开的（卷边铰链、复杂空间件），用 `C.todo_part(code, 厚度, '原因')` 占位，人工补。宁可占位也不要出错的料。

## 自检（每个零件必须做）
- `python3 tools/check.py <订单> 物料号1,物料号2 out.png`：输出 QA（重复线/断头/重复圆弧）并渲染展开图。
- 核对：展开外形尺寸 = 按尺寸手算值；孔数量、孔径、孔位与图纸一致；折弯线位置与条数；标签厚度、件数。

## 焊接件轴测图（2026-11-09 用户定，所有客户）
- **凡是焊接件，下料图那一列都要带轴测图**，给焊工看怎么拼。零件定义里 `C.iso(图号, 整件STEP)` 登记，`layout.build` 自动画：
  - **建块**插在本列**最顶部**：最上面那块零件再往上 150，左右和零件同一条中线，**比例 1（1:1，不缩）**，没有文字说明。
  - 格式照 11-09 用户给的蓝探科样例（NO.441 3380101A00 框架）：块名「客户 订单·yymmdd_HHMMSS·5位号」（如 `蓝探科 NO.441·261006_105351·43497`、
    `沃精 KD1131-0500-Z-01·261109_112316·33416`），块插在 0 层、线型比例 0.5；块内 LINE + ELLIPSE，尖角边 / 轮廓线在「可见 (ISO)」、
    相切边在「可见窄的 (ISO)」，颜色随层（`tools/iso_view.py`，SolidWorks 等轴测方向，Y 向上）。客户名用 `C.customer`（默认蓝探科）。
  - 块比零件宽时列跟着变宽，后面的列整体右移（为了 1:1，这是允许的）。
  - 消隐结果按 STEP md5 缓存在 `STEP/.iso/`（不提交）。
- 只有 SLDASM / SLDPRT：先用 cad2step 转 STEP 再登记。只有二维图没有模型的焊件：README 写「无模型，未出轴测图」，回复里点出来。

## 客户 DWG 上的轴测图（2026-11-19 用户定，所有件）
- **客户 DWG 上画了轴测图的，不论是不是焊接件，下料图那一列顶上都加**，块的位置、插法、块名同上一节（最上面零件再往上 150、同中线、0 层、比例 1）。
  做法照 OneDrive `★ 客户资料 ★/L：蓝探科/蓝探科_图纸.dwg` 里的历史列（690 个这种块，绝大多数比例 1，镜像件比例 -1）：
  - 块内就是客户图上那个轴测视图**原样**（Inventor 模型空间里的大小，不缩放），只取「可见 (ISO)」「可见窄的 (ISO)」两层，颜色随层；隐藏线、中心线、尺寸不取。
  - 镜像件（`C.mirror`，自己没图纸）取源件的轴测图，块 **X 比例 -1** 插。
- 全自动：`layout.build(dwg_iso=True)` 按物料号找 `DXF/<号>.idw.dxf / <号>.dxf / <号>_图纸_1.dxf`，`tools/dwg_iso.py` 认轴测视图
  （「可见」层按包围盒并成视图，斜线 ≥ 40% 且水平线 ≤ 15%，或有椭圆；多个候选取椭圆 + 斜线最多的；伸进框里的别的视图图元剔掉）。
  `python3 tools/dwg_iso.py <dxf>…` 列出每张图的视图和哪个是轴测图。
- 优先级：`C.iso(号, STEP)`（焊接件整件消隐）> 客户 DWG 轴测视图。图纸文件名和物料号对不上时手工登记 `C.iso(号, C.DXF('xxx_图纸_1.dxf'))`（值是 .dxf 就走 DWG 取法）。
- 出图后看 `gen_order` 输出的「轴测图(DWG)」行；拿不准时把所有块拼一张总览图看一遍有没有取错视图（剖视、局部视图误认）。
- 客户图上没有轴测图、也没有 STEP 的：不加，不用说明。
