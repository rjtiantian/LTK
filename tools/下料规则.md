# 下料展开规则（按 NO.441 人工图 + 历史人工图纸 + 用户确认整理）

> 读图口径（图层、投影、孔标注写法、技术要求、BOM/镜像）见 `tools/图纸识读规范.md`。

## 输出格式
- 排版：列间距 = 上一列（零件几何 + 绿色标签 + 黄色表头）包围盒右端 + 750（`tools/layout.py`，`tools/check_layout.py` 自检）。
- 每个零件函数返回 `[(C.lab(厚度, 件数[, 材料]), Piece), ...]`。件数 = 订单数量 `q` × 每台用量（组件按 BOM 明细）。
- 绿色标签只写 `材料-厚度,件数`，如 `SUS304-3mm,2件`、`Q235B-5mm,4件`，禁止加其它字。型材/管材写 `材料-长度mm,件数`（`C.lab(长度, 件数)`）并画截面（`C.tube_rect` / `C.tube_round`）。
- 外购件、机加件（轴、螺杆、标准件）不下料，不出标签。
- 切割轮廓在 `可见 (ISO)` 层（Piece 默认）。轮廓必须闭合、无重复线（同一条边不能画两遍，图纸里的板厚线、反面线、倒角线、中心线、尺寸线都不要）。

## 板厚 / 材料
- 厚度取图纸：剖视图板厚尺寸、技术要求“使用 T=5MM 热板”、或重量反算。SUS304 标题栏材料为 SUS304；Q235B 件材料 Q235B。
- 无库存板厚：15mm → 16mm；SUS304 3.5mm → 4mm（`C.lab` 已自动处理）。

## 折弯展开（外形尺寸法）
- 展开长 = 各边外形尺寸之和 − 折弯数 × BD；`C.bd(t)` 给出 BD（SUS304 / Q235B 表不同，Q235B 件用 `C.bd(t, 'Q235B')`）。
  SUS304: 1→1.7, 1.2→2, 1.5→2.3, 2→3, 2.5→4, 3→5, 4→6.8, 5→8.4, 6→10.5, 8→14, 10→17。
- 某面上的特征距折弯外形交点为 s 时，展开坐标 = 该折弯红线位置 ± (s − BD/2)。
- 90° 折弯：`p.bend(x0,y0,x1,y1,BD)` 画红色中心线 + 两侧蓝线（间距 BD）。
- 非 90° 折弯（如 135°、15°、10°、120°）：按 K 因子中性层算展开（`C.bd_angle`），只画红线：`p.bend(..., 0, red_only=True)`。
- 折弯线只画在折弯区范围内（端点落在轮廓上）。
- 释放槽：只有两条及以上折弯边在角上相碰才做，样式 V 形（`C.relief_params(t, BD)` 给 p=2t, g=2t−BD, s=t+0.1；一边翻边全宽，另一边内缩 s）。不碰角的折边保留图纸原有避让，不另加。

## 孔
- 螺纹孔按小径开孔：`p.tap(x, y, 'M8')`（M3 2.46, M4 3.24, M5 4.13, M6 4.92, M8 6.65, M10 8.38, M12 10.11, M16 13.84）。
- 沉头孔、沉孔只开通孔（如 “Φ9 -3 深” 在 3mm 板上即 Φ9 通孔；沉头 Φ5.5×Φ10.4 只开 Φ5.5）。
- 带正公差的配合孔（如 Φ24 +0.021/0、H7）切割孔径 +0.1；公差上限已 ≥0.1 的按名义尺寸（历史 4020703A 的 Φ56 +0.10/+0.02 人工开 Φ56）。
- 腰形孔 `p.slot(x0,y0,x1,y1,宽)`（两端圆心）。

## 取图纸几何
- 平板件优先直接取视图：`C.plate('文件.dxf', (x0,y0,x1,y1))`，区域稍大于视图外形，会自动去掉同心大圆。
- 视图比例非 1:1（标注值 ≠ 图形长度）要 `.scaled(k)` 还原；有打断画法的用 `C.extract_unbroken`。
- 折弯件的平面视图如果就是真实形状，可先 `C.plate` 取出再在折边处补展开（`C.fold_edge`）；否则按尺寸用 `p.outline([(x,y,圆角R),...])` 手工建模。
- 镜像件（图纸“镜像制作”表）：`C.mirror('镜像件号', '源件号')`。

## 做不了的
- 实在无法可靠展开的（卷边铰链、复杂空间件），用 `C.todo_part(code, 厚度, '原因')` 占位，人工补。宁可占位也不要出错的料。

## 自检（每个零件必须做）
- `python3 tools/check.py <订单> 物料号1,物料号2 out.png`：输出 QA（重复线/断头/重复圆弧）并渲染展开图。
- 核对：展开外形尺寸 = 按尺寸手算值；孔数量、孔径、孔位与图纸一致；折弯线位置与条数；标签厚度、件数。
