# 客户工程图识读规范（蓝探科 Inventor 出图，GB 国标）

整理依据：NO.474 / NO.475 / NO.477-478 共 203 张图纸（DWG 转 DXF）逐张统计，结合 GB/T 4457~4460、GB/T 1804、GB/T 1184、GB/T 197 等国标的通用规定。
用途：读图下料时统一口径，避免误读。下料规则另见 `tools/下料规则.md`。

## 1. 图幅与标题栏
- 图框块 `图框 最新国标`，标题栏块 `标题栏 最新国标`（属性：零件代号、库存编号=零件名称、材料、视图比例、质量、设计人）。
- **零件代号最后一位字母是版本号**（如 7420118**B** 为 B 版）。订单号版本与图纸版本不一致时，按图纸最新版本下料并在说明里写明。
- 标题栏“视图比例”是出图比例，只影响打印。**DXF 模型空间坐标一般为 1:1 真实尺寸**；但个别图整体按非 1:1 画在模型空间（如 1431225A 画成 2:1），必须用“标注值 / 图形长度”核对。
- 左上角倒置的零件代号框为图号章，读图时忽略。
- 质量栏写“无”的，是模型未赋材料；有重量的可用来反算板厚、核对展开面积。

## 2. 投影与视图
- 采用**第一角投影**（GB 默认）：俯视图在主视图下方，左视图在主视图右方，右视图在主视图左方。用相邻视图判断孔在哪个面、折边朝哪边。
- 向视图：箭头加字母“A”标注观察方向，视图上方写“A”或“A 1:2”（带比例的是放大/缩小的局部或向视图）。
- 剖视图：剖切线层 `剖切线 (ISO)`，视图名“A-A”，剖面线层 `剖面线 (ISO)`。
- 局部放大图：边界在 `局部视图边界 (ISO)` 层（双点划线圆），名称“B 3:1”等，**比例非 1:1，取尺寸要按比例换算**。
- 断开画法（长件）：断裂线在 `折线 (ISO)` 层，中间段省略；长度以尺寸标注为准，不能量图（`extract_unbroken` 按尺寸还原）。
- 轴测图：图面角落的立体图，只用于理解形状，不取几何。
- 视图非实形：板面与投影面倾斜时，圆弧画成椭圆（ELLIPSE）、长度缩短（如 15° 小折边、垂直 10° 护栏挡板），展开前要还原实长。

## 3. 图层与线型（Inventor ISO 模板）
| 图层 | 线型 / 颜色 | 含义 | 下料取用 |
|---|---|---|---|
| 可见 (ISO) | 粗实线 / 白 | 可见轮廓线 | 取（轮廓、孔） |
| 可见窄的 (ISO) | 细实线 / 白 | 折弯切线、相切边 | **不取**（不是切割线） |
| 隐藏 (ISO) / 隐藏窄的 (ISO) | 虚线 / 蓝 | 不可见轮廓、背面孔 | 不取，用于判断背面特征 |
| 中心线 (ISO) / 中心标记 (ISO) | 点划线 / 红 | 孔中心、对称线 | 不取，用于定位孔心 |
| 尺寸 (ISO) | — | 尺寸、引线 | 读数用 |
| 符号 (ISO) | — | 粗糙度、焊接、基准等符号 | 读数用 |
| 折线 (ISO) | — | 断裂线 | 读长度用 |
| 草图几何图元 (ISO) | — | 草图辅助线 | 不取 |
- 板厚线、反面轮廓（与正面轮廓相距板厚或 t·tanα）在侧视/小角度折边视图里成对出现，下料只保留一圈。

## 4. 尺寸标注（标注样式“默认 (GB)”）
- 线性尺寸以实际测量值为准；尺寸文字带括号如“(238.56)”为参考尺寸，可用于核对，不作制造依据。
- 未注公差：GB/T 1804-m（6~30 ±0.1，30~120 ±0.15，120~400 ±0.2，400~1000 ±0.3 …）；未注形位公差 GB/T 1184-K。
- 带公差的配合尺寸写成“Φ24 ⁺⁰·⁰²¹₀”“Φ46 H7”“Φ56 ⁺⁰·¹⁰₊₀.₀₂”“30 ⁺⁰·¹₊₀.₀₅”：激光切割孔径 +0.1；上限已 ≥0.1 的按名义（见下料规则）。
- 角度：折弯角标“90°/135°/165°”等为两面夹角，偏折角 = 180° − 标注角；“120°”若标在板面内（折弯线与边线夹角），不是折弯角（如 7420739A）。
- 外形尺寸：钣金件的翼边、翻边尺寸一般标到外表面（外形），按外形尺寸法扣 BD 展开；“内”尺寸或标到内表面的要先换算。

## 5. 孔与螺纹的标注写法（Φ 在 DXF 中以 AIGDT 字体字母 n 表示）
| 写法 | 含义 | 下料 |
|---|---|---|
| `4-Φ9 通孔` | 4 个 Φ9 通孔 | 开 Φ9 |
| `2-Φ11 -3 深` | Φ11 深 3（深度 ≥ 板厚即通孔） | 板厚 ≤ 深度时开通孔 |
| `12-Φ5.5 -2.5 深 ⌵ Φ10.4 X 90°` | Φ5.5 孔 + 90° 沉头，沉头直径 Φ10.4 | 只开 Φ5.5 |
| `1-Φ9 通孔 ⌴ Φ15 ↧ 3`（v/↧ 符号） | 沉孔（平底），沉孔 Φ15 深 3 | 只开通孔 |
| `4-M10 - 6H` | 4 个 M10 内螺纹，6H 公差 | 开底孔（M10→Φ8.38） |
| `4-M8 - 6H ↧ 22.2` | M8 螺纹深 22.2（多为焊接螺母/厚件） | 开底孔 Φ6.65 |
| `5-Φ11 通孔 上下对称` | 上下两侧对称布置 | 两侧都开 |
| `-贯通` / `-通孔` | 贯通 | 通孔 |
| `8-Φ8.5 EQS` / `PCD.Φ115` | 均布 / 节圆直径 | 按节圆均布 |
- 标注数量只对应所指的那一组；隐藏线或对面视图显示另一侧也有孔时，以视图为准并在说明中列出（如 0160408A01 “2-Φ9” 实为两侧各 2）。

## 6. 技术要求（标题栏上方）
常见条目及下料处理：
- “飞边去毛刺 / 去除边角毛刺”：后处理，不影响展开。
- “未注倒角 C0.5 / 0.5×45°”：倒角不下料；“未注倒角 C1、C5、C10、C15”等大倒角要切出。
- “未注圆角 R5 / R6 / R10”：外形未标的尖角按此圆角切（图上已画出的以图为准）。
- “表面拉丝（处理）/ A面拉丝 / 使用拉丝不锈钢板 / 覆膜拉丝板”：表面列写 `SUS304-拉丝`，A 面为拉丝面。
- “表面烤漆 RAL 9007 / 喷砂后烤漆 RAL9007”：表面列写 `Q235B-RAL9007`。
- “表面喷砂处理”“表面镀镍”：写 `SUS304-喷砂` / `…-镀镍`。
- “使用 T=5MM 热板制作”：板厚 5mm（标题栏不写板厚时以此为准）。
- “整体焊接牢固，焊接处打磨平整”等：焊接件，按 BOM 分子件下料。

## 7. 组件、BOM 与镜像
- 组件图带“明细栏”：序号 / 代号 / 库存编号(名称) / 数量 / 材料 / 单重 / 总重；数量为每台用量，下料件数 = 订单数 × 用量。子件图为同号 `xxx.idw_图纸_N`。
- 明细栏里的外购件、标准件（螺栓、铆螺母等）不下料；方管、圆管按“规格-长度”写在明细栏代号或名称里，按长度出料。
- 引出序号（气泡 ①②）对应明细栏序号；焊接符号块 `焊接符号标识符` 表示焊缝。
- “制作方式”小表：`如图制作 xxxA / 镜像制作(对称制作) yyyA`——镜像件没有单独图纸，按源件左右镜像下料。
- 图面“沿此线镜像（制作）/ 以此线为基准镜像”：零件以该线对称，图上只画一半，展开时补全另一半。

## 8. 钣金专项
- 折弯处“1 × 1”小方口、“3 × 7.5”等为图纸自带释放口，照图切；两条以上折弯碰角处按我方 V 形释放槽样式。
- 小角度折边（165°、170°）在主视图中被投影缩短，按 1/cos 还原；“垂直 10°”护栏挡板的板面本身为实形，只有小折边缩短。
- 卷圆件标“Φ1105 / Φ895”时先确认是内径还是外径（看两条弧的半径），按中性层算弧长。
- 板厚：剖视图“2.5”“3”等小尺寸、侧视图板厚，或技术要求 T=；SUS304 无 3.5、15 等非常规板厚时按用户确认规则替换。
- 图面“两块板，孔对齐”“铆接螺母”等文字说明要逐条落实到下料（如孔径按铆螺母要求）。
- **C 形 / U 形件两翼边只画了一个侧视图时，不能默认另一翼边是平直的**（NO.474 的 0185708A 曾因此出错）。按以下方法判断另一翼边，并逐条核对：
  - 端视图：两个翼边上是否都有孔的隐藏虚线（有就两边都开孔）。
  - 侧视图：在斜角、缺口、圆角被切掉的地方，有没有露出另一翼边的轮廓线。没有露出，说明两翼边同形，斜角、圆角、孔都要两边做。
  - 轴测图上看得到的那部分。
  - 用标题栏重量核对展开面积（注意密度取值）。
  - 确实无法判断的，列入“需人工复核”并在回复里明确告诉用户，不能只写在 README 里。
