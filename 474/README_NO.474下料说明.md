## 排版规则（参照 NO.441 人工下料图）
- 每个清单行一列；最下方黄色表头：`日期·序号·订单·物料号·名称·数量·表面`
- 表头上方绿色标签，只写 `材料-厚度,件数`（如 `SUS304-3mm,2件`）；型材/管材按 NO.441 写 `材料-长度,件数`
- 组件按子件逐个向上排列，件数 = 订单数 × 子件用量
- 切割轮廓在 `可见 (ISO)` 层；折弯线在 `折弯线` 层：红色中心线 + 两侧蓝线（间距 = 折弯扣除 BD）；非 90° 折弯（15°/10° 小折边、135° 等）只画红线（同 441 的 4020142B 及历史 1530201A）
- 展开长 = 各边外形尺寸之和 − 折弯数 × BD（SUS304 BD 表见 `SUS304 折弯计算.png`）；非 90° 折弯按 K 因子中性层计算
- 螺纹孔按小径开孔（M4→Φ3.24，M5→Φ4.13，M6→Φ4.92，M8→Φ6.65，M16→Φ13.84，M20→Φ17.29）；沉头孔只开通孔
- 释放槽按 `474/释放槽样式.dxf`，只用于两条及以上折弯边碰角处：p = 2t、g = 2t − BD、s = t + 0.1（如 3mm：p=6、g=1、s=3.1），
  一边翻边全宽、另一边内缩 s，V 形槽尖伸入 p×p。本单用到的：0185754A 两个后角、0185732A 侧板与前耳片/底回折的三个角。
  不碰角的局部翻边（0185727A01 耳片、小角度折边护栏挡板等）保留图纸原有避让，不做释放槽
- 图纸中的打断画法（长件）按尺寸标注自动还原为真实长度；视图比例非 1:1 的按标注缩回实际尺寸（如 1431225A 为 2:1 视图）
- 带正公差的配合孔（Φ24 +0.021、Φ46 H7、Φ51 +0.03）切割孔径 +0.1（同历史 1431220A：Φ24→Φ24.1）
- SUS304 没有 3.5mm 板料，按 4mm 下料（同历史 1431226A）
