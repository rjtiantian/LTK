# 南方2750钣金（上海炬欣，2026-10-20）展开图

- 生成：`python3 tools/gen_order.py 单件/2026-10-20-南方2750` → `展开图_南方2750.dxf`（零件定义 `tools/ps20261020nf.py`）
- 来源：`南方2750钣金.rar`，每件一个 STEP（SolidWorks 2017，取几何）+ 一个 DWG（取件数、螺纹、方管规格）
  - DWG 里的中文是 CP932 编码，LibreDWG 转出为 `\M+1xxxx`，已按 CP932 译出；DWG 转 DXF 有坏句柄，ezdxf 需跳过对象表才能读
- 展开：`python3 tools/step_unfold.py STEP/<件>.STEP JSON/<件>.json --bd <BD>`（平行折弯件，外形尺寸法）；
  平板件 `--plate auto`（或指定平面）取面轮廓
- 自检：QA 0 问题，排版异常 0；展开面积 × 板厚与模型体积相差 1.2%~1.5%（BD 与 SolidWorks 折弯系数不同）
- 材料均 SUS304，表面拉丝
